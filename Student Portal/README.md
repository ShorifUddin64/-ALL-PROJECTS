# Student Portal - Professional Edition 🎓

This is a professional Student Portal built with "Java Swing". It helps to manage student profiles and course records easily.

## Features:

* Student Management:Add, update, delete, and view student details.
* Course Tracking:Search and filter students instantly by course name.
* Modern UI:Clean design with custom background colors and status indicators.
