# 🏫 Smart School-College Management System 📚

This is a comprehensive management system built with **Java**. It helps to manage student records, attendance, and school administration efficiently.

## 🚀 Features:
* **Student Management:** Add, update, and view student details.
* **Attendance System:** Track daily attendance easily.
* **Teacher Records:** Manage faculty information.
* **Database Support:** Securely store all school data.
